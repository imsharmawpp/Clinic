# 01 — Project Overview

## Product Name

**ClinicPro SaaS**

## Description

Cloud-based Clinic Management Software built for Indian healthcare market.

### Frontend
- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5.3

### Backend
- PHP 8.3
- MySQL 8.0
- PDO (Prepared Statements)

### Architecture
- MVC Pattern
- Repository Pattern
- REST API Ready
- Multi-Tenant (clinic_id isolation)
- White Label Ready
- License-Protected

## Objectives

Digitize clinic operations:
- Patient Registration & History
- Appointment Scheduling & Token System
- OPD Visits & Diagnosis
- Billing & Invoicing (GST)
- Prescriptions
- Lab Management
- Pharmacy & Inventory
- Reports & Analytics
- Audit Trail

## Target Market

| Tier | Segment |
|------|---------|
| Tier 1 | Single Doctor Clinics |
| Tier 2 | Dental / Skin / Eye Clinics |
| Tier 3 | Multi-Doctor Clinics |
| Tier 4 | Diagnostic Centers / Small Hospitals |

## USP

- One-time license sale (no recurring billing for clients)
- White-label ready (logo, colors, branding)
- Self-hosted (clients own their data)
- No composer dependency (pure PHP, easy to deploy)
- Web installer (no CLI needed)
- Indian market focus (INR, GST, Aadhaar-ready)
